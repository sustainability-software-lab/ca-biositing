## Rule
1. Put the class in the right `models/<domain>/` module with `table=True`.
2. Re-export it from `models/__init__.py`. Without this, Alembic autogenerate does not see it (AGENTS.md, `models/__init__.py` comment).
3. Generate and review a migration: `pixi run migrate-autogenerate -m "..."`, then `pixi run migrate`.
4. Materialized views under `data_portal_views/` are excluded from autogenerate; use `pixi run compile-mv-fixes -m "..."`.

## Why
Alembic reads `SQLModel.metadata`, which only contains imported tables (`alembic/env.py:25,44`).

## Caveat
Migrations are linear: rebase onto `upstream/main` before adding a revision (`src/ca_biositing/datamodels/AGENTS.md`, "Linear Alembic Chain").
