## How it works
- Charts are produced by analysis scripts and the dashboard generators into exports/plots/ on a developer machine.
- CI produces the dashboards into exports/plots/ inside the runner and publishes them to GCS (architecture/ci-dashboard-artifacts-publisher).
- The Pages site reads GCS latest/ (architecture/ci-gh-pages-gallery-consumer).

## Gotchas
- Do not treat data_summary_report.md counts as current without re-running the source script.
- exports/gallery.md lists figures that no script produces in this repo (see bugs/analysis-gallery-stale-entries).
- Nothing under exports/plots/ is published by git any more. The old statement that gh-pages deploys this tree on push is no longer true.
